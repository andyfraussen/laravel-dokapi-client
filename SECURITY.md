# Security Policy

## Supported versions

Security fixes are maintained for the latest release in the current stable major
version. Update to the latest patch release before reporting a suspected issue.

| Version | Security updates |
| --- | --- |
| 3.x, latest release | Supported |
| 2.x and earlier | Not actively maintained |

Reports affecting an older version are still useful when the issue may also affect
the current release.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/andyfraussen/laravel-dokapi-client/security/advisories/new).
You can also find this under **Security → Advisories → Report a vulnerability** in
the repository.

Include the affected package version, PHP and Laravel versions, the expected and
observed behavior, the potential impact, and a minimal reproduction when possible.
Use synthetic invoice or KYC data and redact credentials, access tokens, webhook
secrets and presigned URLs.

Keep vulnerability details out of public issues and pull requests while the report
is being reviewed. Reports are investigated privately, and a fix and public
advisory can be coordinated with the reporter when appropriate. Response and fix
times depend on the issue and maintainer availability.

For ordinary bugs and feature requests, use the repository's public issue tracker.
