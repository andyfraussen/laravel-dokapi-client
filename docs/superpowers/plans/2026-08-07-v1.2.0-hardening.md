# v2.0.0 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release v2.0.0, fixing Dokapi request-boundary defects, adding Laravel 13 support, dropping security-EOL Laravel 11 support, and verifying the supported matrix in CI.

**Architecture:** Keep the public client and resource API intact. Add private request-boundary helpers to `DokapiClient`: API routes resolve against the configured base URL; presigned uploads have a separate minimal option set; and token caching uses a 60-second safety margin. Focused Guzzle history tests protect those boundaries.

**Tech Stack:** PHP 8.3+, Laravel Illuminate Cache/Support 12–13, Guzzle 7, Orchestra Testbench 10–11, PHPUnit, Larastan, GitHub Actions.

## Global Constraints

- Preserve all existing public resource and DTO method signatures.
- Support PHP `^8.3`, Laravel/Illuminate 12 and 13, and Guzzle 7 only.
- Drop Laravel 11 because its security support ended on 12 March 2026 and Composer blocks all framework versions with active advisories.
- Keep Composer's lock file ignored; each CI matrix job resolves its own dependencies.
- The only added configuration value is `dokapi.webhook_secret` / `DOKAPI_WEBHOOK_SECRET`.
- API and OAuth requests retain `dokapi.http`; presigned uploads never inherit it.
- A token is cached only when a positive numeric `expires_in` exceeds 60 seconds.
- No tag is created until the pull request is merged to `main`.

private function resolveApiUrl(string $path): string
{
    if (filter_var($path, FILTER_VALIDATE_URL) !== false) {

    return rtrim((string) ($this->config['base_url'] ?? ''), '/') . '/' . ltrim($path, '/');

    return rawurlencode($value);
}
